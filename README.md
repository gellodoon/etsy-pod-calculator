## 💡 About The Project

Selling Print-on-Demand products on Etsy involves complex fee structures (listing fees, transaction fees, payment processing fees) combined with production and shipping costs from suppliers (like Printify or Printful). 

This **Etsy POD Profit Calculator** simplifies the process. Built entirely with vanilla HTML, CSS, and JavaScript, it provides a seamless client-side experience to help sellers instantly determine their exact profit margins before launching a product.

## ✨ Key Features

- **Real-time Calculations:** Instantly see your net profit as you adjust pricing, costs, or shipping rates.
- **Accurate Etsy Fees Breakdown:** Automatically calculates the $0.20 listing fee, the 6.5% transaction fee, and standard payment processing fees.
- **POD Integration Ready:** Input fields tailored for supplier production costs and shipping fees.
- **Single-Page Application (SPA):** No page reloads, no server delays. Everything runs locally in your browser.
- **Responsive Design:** Works perfectly on desktop, tablet, and mobile devices.

## 🛠️ Built With

- **HTML5:** For the semantic structure of the calculator.
- **CSS3:** For a clean, modern, and responsive user interface.
- **JavaScript (Vanilla):** For the real-time calculation logic and dynamic DOM manipulation.

## 🚀 How to Use

1. Access the calculator via the **[Live Demo Link](ضع-رابط-صفحة-github-pages-هنا)**.
2. Enter your intended **Sale Price**.
3. Input the **Production Cost** charged by your POD provider.
4. Add the **Shipping Cost** (both what you charge the customer and what the provider charges you).
5. The calculator will automatically deduct all Etsy fees and display your **Net Profit** and **Profit Margin Percentage**.
